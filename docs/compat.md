# Compatibility with ImageJ

Calipix aims to give the same results as ImageJ 1.x: exactly for integer
results, thresholds and counts, and within 1e-5 relative error for floating
point. This file records what has been checked and every place where Calipix
knowingly differs.

Status key: **verified** means compared against output generated by ImageJ;
**from source** means implemented from the ImageJ source and not yet compared.

The target is **ImageJ 1.54p**, the version that generates the reference
files. Later versions differ in places (for example, integer Gamma, Log, Exp
and Square Root truncate in 1.54p and round in 1.54u), so port from the
1.54p source and let the reference files decide.

Reference files are in `fixtures/imagej/out`, written by ImageJ itself from
the macros in `fixtures/imagej/gen`. `cargo xtask gen` regenerates them and
`cargo xtask verify` checks they are reproducible.

## TIFF

Read results are checked against all 31 TIFFs ImageJ wrote into
`fixtures/imagej/out`. Written files were opened in ImageJ 1.54p and compared
with the source image (14 of 14 cases), and four re-saved little-endian files
are byte-identical to ImageJ's.

| Behaviour | ImageJ source | Status |
|---|---|---|
| ImageJ stacks are read by offset (plane k at first strip offset + k x plane bytes); further IFDs are ignored once `images=N` is present | `TiffDecoder`, `FileOpener.openStack` | verified, including a 4.38 GiB single-IFD stack |
| channels, slices and frames are used only if their product is the stack size; otherwise a plain Z stack | `FileOpener.setCalibration` | verified |
| Pixel size from the resolution tags; unit, spacing, frame interval and origins from the description; "um" becomes "µm" | `TiffDecoder.OpenIFD`, `FileOpener.decodeDescriptionString` | verified |
| Resolution-unit rules for files not written by ImageJ | `TiffDecoder.OpenIFD` | from source |
| Display ranges, per-channel LUTs and default channel colours | `FileOpener.setCalibration`, `CompositeImage.setupLuts` | verified |
| Composite, color and grayscale modes | `Opener.makeComposite` | verified |
| 8-bit images with a colour or inverting LUT are palette TIFFs | `TiffDecoder.getColorMap`, `TiffEncoder.writeColorMap` | verified |
| WhiteIsZero: samples unchanged, inverting LUT | `FileOpener.createColorModel` | from source |
| Signed 16-bit is stored unsigned with a calibration function; loaded as true signed values | `Calibration.isSigned16Bit` | verified |
| Info text, slice labels, image properties, selection and overlay | `TiffDecoder.getMetaData`, `TiffEncoder.writeMetaData` | verified |
| Multi-page files from other software: a stack if all pages match, else the first image | `Opener.openTiffStack` | from source |
| Written layout and description string | `TiffEncoder`, `FileSaver.getDescriptionString` | verified |
| Stacks of 4 GiB or more are written with a single IFD | `TiffEncoder.write` | layout verified in ImageJ at small size; not run at real size |

## Intentional differences

| Area | ImageJ | Calipix | Why |
|---|---|---|---|
| Pixel types | 8-bit, 16-bit unsigned, 32-bit float, RGB | Also signed and 32/64-bit integers, 64-bit float, complex | ImageJ2's data model supports them. Operations on types ImageJ 1.x lacks follow its 16-bit rules (integers) or 32-bit rules (floats). |
| RGB | A packed pixel type | Three 8-bit channels flagged as RGB | One code path for all kernels; macros will still see packed values. |
| Grey PNG with alpha or a transparent colour | Grey levels brightened (a linear-to-sRGB conversion in Java) before blending over white | Stored levels blended over white | Java artefact; no other PNG is treated this way |
| Transparent colour in a grey PNG below 8 bits | Honoured only when it is 0 | Honoured | Java bug |
| 16-bit RGB PNG | Composite with three slices | Three channels flagged as RGB | Consistent with 16-bit RGB TIFF |
| Saving an 8-bit image with a display range as PNG | Range applied to the samples | Sample values saved | No silent data change |
| Saving a stack as PNG | Saves only the slice shown | Refused, suggests TIFF | No silent data loss |
| TIFF pixel types | 32-bit integers become float; 64-bit and signed 8-bit are misread | Kept as stored | No silent conversion |
| 16-bit RGB TIFF | Composite with three slices | Three channels flagged as RGB | Consistent with 8-bit RGB |
| TIFF variants | Refuses tiles, BigTIFF, OME-TIFF and the floating-point predictor | Opens them | Wider compatibility |
| RGB display range | Rewrites the pixel values | Display only | Looking never changes data |
| Zoom below 100% | Platform-dependent smoothing | Mean of displayed colours over a fixed grid | Deterministic, and the same on CPU and GPU |
| Composite with the first channel hidden | First pixel keeps a stale colour | Correct colour | ImageJ bug |
| Display range with max below min | Ignored or wrapped | Everything shows as level 0 | One defined result |
| Saving 16-bit or float as JPEG, GIF or BMP | Saves the 8-bit display rendering | Refused, asks to convert first | No silent data change |
| Saving with a LUT or display range as JPEG | Burned into the pixels | Sample values saved | Same |
| RGB GIF with more than 256 colours | Quantised | Refused | Lossy step left explicit |
| Truncated GIF | Opens partly black | Error | No silent data loss |
| JPEG chroma | Subsampled below quality 90 | Never subsampled | Encoder limitation; files are larger and closer to the source |
| Gaussian blur of a narrow selection near the left edge | Also overwrites samples beside the selection | Only the selection changes | ImageJ bug |
| Display range after Variance, Top Hat, Convolve | Reset or stretched | Unchanged | Process commands change samples, not the display |
| Convolve kernel text | Unreadable values count as 0 | Refused, naming the value | No silent data change |
| Shadows | Eight commands | One command with a direction | One place in the menu |
| Smooth, Sharpen, Find Edges, Despeckle, Remove Outliers, Remove NaNs, Shadows | Process, Process > Noise, Process > Shadows | Process > Filters | Two menu levels at most |
| Reciprocal, NaN Background on integer images | Does nothing, silently | Error saying a float image is needed | Say what happened |
| Image Calculator without "stack" | Current slice of each image | Planes at the same position | A command cannot see the second image's view |
| 8-bit to 8-bit conversion | Burns the display range into the samples | Only replaces a colour LUT with grey | No silent data change |
| RGB Color on channels shown one at a time | One RGB slice per channel | Refused, asks for composite mode | Not one picture |
| Canvas Size, Rotate with enlarge, Size | Pixel origin unchanged | Origin moves or scales with the picture | Coordinates stay on the same features |
| Flipping a calibrated stack | Origin toggled once per slice | Mirrored once | ImageJ bug |
| Saved rotated rectangle | Reads back as a polygon | Stays a rotated rectangle | The file says what it was |
| Inverse of a selection crossing the image edge | Tie pixels can be in both the selection and its inverse | Exact complement | One defined result |
| Combining selections | Geometric | On masks, with the outline along pixel edges | Same pixels; perimeters of slanted shapes differ |
| Enlarge with nothing left | Leaves the selection unchanged | Error saying so | Say what happened |
| ROI set file timestamps | Current time | Fixed | Same input, same bytes |
| Restore Selection | One global previous selection | Not available; use undo | No hidden state |
| Spline-fit, text and image selections | Supported | Flag kept only, or refused | Not yet built |
| A selection that covers no pixel, or lies outside the image | Does nothing, or measures NaN | Error saying which | Say what happened |
| Plot Profile with an angle selection | Column average of its bounding box | Refused | Not a meaningful profile |
| A selection cut by the image edge after Crop or Duplicate | Geometric intersection | Same pixels, outline along pixel edges | No geometric clipping yet |
| Group columns in Results | Group, GroupName | Not present | Selections carry no group yet |
| Measurement settings | Global preference | Belong to the session, appear in History, undoable | A recorded workflow must not depend on hidden state |
| Results text line endings | Platform-dependent | Always LF | Same file on every machine |
| Set Scale "Global" | Also applies to images opened later | Applies to images open now | No hidden state |
| Processing a composite image | Acts on the current channel | Acts on every channel shown together | The viewer has no "current channel" in composite mode; name a channel to restrict it |
| Opening zoom | 100%, in a window sized to the image | Largest standard zoom step at which the image fits the tab | One window; small images should not be specks |
| Mouse wheel | Scrolls through a stack | Zooms about the cursor; Shift+wheel steps through the stack | Matches other image viewers; see `docs/ux.md` |
| Undo | One step, some commands only | Every command, unlimited steps; saving is not undone | Images are immutable snapshots that share unchanged planes. |
